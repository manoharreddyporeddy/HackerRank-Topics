# Security Policy

## Reporting a Security Vulnerability

For security reports, please use the
[security report form](https://www.twoanswers.com/security-report)
or the [contact form](https://www.twoanswers.com/contact).

Please do not report security vulnerabilities through a public GitHub issue.

When reporting a vulnerability, please provide enough information to help us understand and reproduce the issue, if possible.

Thank you for helping keep the project secure.
